▦ NexoKit / PDF Toolkit

Organiza tus PDF

Une documentos, selecciona páginas, cambia su orden y gíralas. El procesamiento se realiza en tu navegador.

1. Añade tus PDF

📄
Selecciona o arrastra archivos PDF

Puedes elegir varios a la vez.

Los archivos protegidos con contraseña no son compatibles. Para cambiar el orden de documentos, usa ↑ y ↓.

2. Elige las páginas

Marca las páginas que quieras conservar. Usa las flechas para reordenarlas y ↻ para girarlas 90°.

Añade un PDF para empezar.

Las miniaturas muestran el contenido real de cada página. Para cargarlas se necesita Internet la primera vez (biblioteca PDF.js). Los documentos no se envían a ningún servidor.
